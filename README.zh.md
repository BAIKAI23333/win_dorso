# WinDorso

mac有dorso项目保护人们的颈椎和脖子，而window似乎没有类似的开源项目，这是我不愿意看到的（qwq）

本项目为[tldev/dorso](https://github.com/tldev/dorso)（macOS 坐姿监测应用）的 Windows版。通过摄像头实时监测坐姿（其实是头部高度），当你弯腰低头时屏幕出现视觉提醒，坐直后消失。**所有处理均在本地完成，画面绝不离开你的电脑。**

## 功能特性

- **摄像头姿态检测** — MediaPipe Pose（33 个关键点），纯 CPU 实时运行
- **自动校准** — 坐直片刻即可完成校准；基线自动保存，每次启动复用
  （归一化坐标，换摄像头分辨率也不失效）
- **5 种警告样式** — 模糊、光晕、边框、全屏、无
- **文字提醒可叠加** — 自定义文字，九宫格屏幕位置，可与任意样式组合
- **自定义颜色** — 8 个具名色板 + 完整调色盘
- **检测参数可调** — 灵敏度、容忍度（死区）、延迟（0–1 秒）、
  检测频率（5–30 帧/秒）
- **离开模糊** — 离开摄像头约 3 秒后自动变暗，强度独立可调，
  按住拖动实时预览
- **严格模式** — 可选：低头时锁定鼠标，坐直才能操作
- **全局快捷键** — 任意位置一键开关监测（默认 `Ctrl+Alt+D`，
  点击录制自定义组合）
- **暗色/亮色主题**、**中/英界面切换**
- **可缩放窗口 + F11 全屏**，窗口尺寸跨启动记忆
- **多显示器**覆盖，跟随分辨率/旋转变化
- **防误触** — 滚轮永远不会改动下拉框/滑块的值
- **开机自启**（写入注册表）

## 环境要求

- Windows 10/11
- 摄像头
- Python 3.11+（[python.org](https://www.python.org/downloads/) 官方安装包
  或 Microsoft Store 均可）

> **本项目开发环境**：使用 Miniconda 虚拟环境开发（conda 环境名
> `win_dorso`，Python 3.11）。下方安装说明以标准 `venv` 为主，任何人不装
> conda 也能运行；conda 仅作为备选方案列出。

## 安装

使用标准 `venv`（推荐）：

```powershell
cd path\to\win_dorso
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

如果你平时用 conda，也可以：

```powershell
conda create -n win_dorso python=3.11
conda activate win_dorso
pip install -r requirements.txt
```

> `requirements.txt` 为测试环境的 `pip list` 全量快照；另附
> `pyproject.toml` 声明顶层依赖（`pip install .` 亦可安装）。

## 运行

```powershell
# venv
.venv\Scripts\activate
python main.py

# 或 conda
conda activate win_dorso
python main.py
```

首次启动会提示你保持正确坐姿，自动完成校准并保存；此后启动若已有校准，
摄像头画面会自动收起。

## 使用说明

| 控件 | 作用 |
|---|---|
| **开始/停止监测** | 手动开关（快捷键同样生效） |
| **重新校准** | 自动展开摄像头画面并重新记录基准坐姿 |
| **灵敏度** | 越高，低头越容易触发提醒 |
| **容忍度** | 允许轻微低头不提醒的范围，数值越高越宽松 |
| **延迟** | 0–1 秒；低头持续该时长后才触发提醒 |
| **检测频率** | 每秒姿态判定次数（松手后生效） |
| **警告样式** | 模糊 / 光晕 / 边框 / 全屏 / 无 |
| **文字（可叠加）** | 在九宫格位置之一叠加自定义文字 |
| **颜色** | 8 个具名色块或自定义颜色 |
| **覆盖强度** | 1–10，视觉效果的力度 |
| **低头时锁定鼠标** | 严格模式：遮罩拦截点击，坐直才恢复 |
| **离开摄像头时自动模糊屏幕** | 约 3 秒无人脸后屏幕变暗 |
| **离开模糊强度** | 按住拖动实时预览效果 |
| **开机自启** | 注册表 Run 项 |
| **暗色模式** | 暗/亮主题切换 |
| **语言** | 中文 / English |
| **快捷键** | 点击后按下新组合键录制（Esc 取消） |

## 项目结构

```
win_dorso/
├── main.py              # 入口（单实例互斥、Qt 中文翻译）
├── main_window.py       # 设置窗口（主题/i18n/响应式布局）
├── posture_detector.py  # MediaPipe 检测线程
├── blur_overlay.py      # 多显示器覆盖窗口（样式 + 文字层）
├── calibration.py       # 归一化基线 + 平滑偏差计算
├── config.py            # QSettings 持久化（线程安全）
├── i18n.py              # 中英翻译层
├── pyproject.toml       # 项目元数据与顶层依赖
└── requirements.txt     # pip 全量快照
```

## 设计说明

- 所有处理**纯本地**，视频帧不出进程。
- 覆盖窗口默认鼠标穿透（`WS_EX_TRANSPARENT`）；开启严格模式后有意拦截
  点击。
- 摄像头枚举在检测启动**之前**完成（4 秒兜底），保证 DSHOW 设备不会被
  两个消费者同时打开——这对虚拟摄像头尤其重要。
- 配置存于注册表（QSettings），加锁保护（检测线程读、界面线程写）。

## 已知限制

- "模糊"样式是半透明变暗的近似效果——Windows 的逐像素透明窗口无法对
  其他窗口做真正的背景模糊。
- 小键盘按键不能录制成快捷键组合（VK 键码与主键盘不同）。
- 同一时间只能运行一个实例（互斥锁强制）。
